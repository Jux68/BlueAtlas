BLUEATLAS ALPHA 0.9.0 — BLUE LAGOON

Déploiement GitHub Pages depuis un iPhone :
1. Décompresser le ZIP dans l'application Fichiers.
2. Ouvrir le dépôt Jux68/BlueAtlas dans Safari.
3. Remplacer les fichiers présents à la racine par ceux de ce dossier.
4. Commit recommandé : release: BlueAtlas Alpha 0.9.0.
5. GitHub Pages republie automatiquement la branche main.

Mise à jour de la PWA :
- Ouvrir d'abord le site dans Safari et actualiser la page.
- Fermer puis relancer l'icône BlueAtlas.
- Si l'ancienne interface persiste, supprimer l'icône de l'écran d'accueil puis l'ajouter à nouveau.

Conservation des données :
- La clé de stockage de la 0.8.1 est conservée : expéditions, observations et photos restent disponibles sur la même URL.
- Créer malgré tout une sauvegarde depuis Profil avant le déploiement.

Aucune commande de build n'est requise.
